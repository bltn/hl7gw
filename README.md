# hl7gw

A lightweight, self-hosted HL7v2 gateway built for 2026 not 2003.

## Why hl7gw?

Like many engineers unfortunate enough to need an HL7v2 feed integration, I run Mirth Connect at work. It does the job, but it's a complete PITA to run:

- A JVM and a database server to install and maintain
- A 2003-era desktop GUI
- Java on your laptop just to check a feed
- Next to no observability
- mTLS means bolting on HAProxy

I built hl7gw as an answer to "how would this thing look if it was built for engineers in 2026, not hospital IT admins in 2003":

- **A binary, not an install.** No JVM, no database server, no desktop client. Just SQLite and plain files.
- **mTLS built in, not bolted on.** Turn it on per channel in the config. No HAProxy in front.
- **A config file, not a GUI.** One JSON file, generated by a setup wizard.
- **A CLI, not a control panel.** `hl7gw messages`, `replay` and `process` talk to the running gateway over a unix socket and print JSON, or a readable view with `-pretty`.
- **Observable by default.** Structured logs, Prometheus metrics and health probes, zero setup.

## Getting started

```sh
# 1. Download the binary
curl -fsSL "https://github.com/bltn/hl7gw/releases/latest/download/hl7gw_$(uname -s)_$(uname -m).tar.gz" | tar -xz

# 2. Answer a few questions; writes hl7gw.json
./hl7gw configure

# 3. Put your API's token in the file the wizard names, then run.
#    run picks up hl7gw.json from the current directory (-config for another path).
./hl7gw run

# 4. In another shell (same directory, or add -config): list what came in, read one, replay one
./hl7gw messages adt
./hl7gw messages adt 42
./hl7gw replay adt 42
```

## How it works

hl7gw receives HL7v2 over MLLP, persists it to SQLite, POSTs it to your API as
XML, and only then ACKs the sender.

See the [architecture doc](ARCHITECTURE.md) for more details.

## Development

```sh
make build        # bin/hl7gw
make configure    # go run . configure -output hl7gw.json
make run          # go run . run -config hl7gw.json
make check        # lint, unit + e2e tests with a 100% coverage gate & short fuzzing run
make e2e_tests    # black-box tests against the built binary
make fuzz FUZZTIME=30s
make dist         # release archives + checksums into dist/
```
